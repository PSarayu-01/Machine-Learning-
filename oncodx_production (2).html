# Feature Type Engineering Step Transformation SHAP Importance
⚖️ BMI Engineering
BMI is a derived feature — computed from Weight and Height. It's then categorised and risk-scored.
BMI = weight_kg / (height_m)²
bmi_category = cut(BMI, bins=[0,18.5,25,30,∞])
bmi_risk_flag = 1 if BMI <18.5 or BMI >30
Underweight (<18.5)High risk ⬆
Normal (18.5–24.9)Baseline ✓
Overweight (25–29.9)Moderate ⚠
Obese (≥30)High risk ⬆
❤️ Vitals Feature Engineering
Continuous vitals are transformed into binary flag features + normalised scores to capture clinical thresholds.
pulse_normal = 1 if 60 ≤ pulse ≤ 100
rr_normal = 1 if 12 ≤ RR ≤ 20
vitals_score = Σ(normal flags) / total_vitals
age_group = cut(age, [0,18,40,60,70,120])
These binary flags prevent the model from treating a pulse of 59 and 61 as very different, while correctly flagging 45 bpm as abnormal.
📐 Categorical Encoding
Categorical features are encoded using Label Encoding for ordinal data and Target Encoding for high-cardinality cancer types.
Cancer Type → Target Encoding
cancer_encoded = mean(drug_response) per cancer type across training set. Preserves frequency signal better than OHE for 80+ categories.
Stage → Ordinal Encoding
Stage I=1, II=2, III=3, IV=4, Unknown=0. Preserves clinical ordering (severity increases with stage).
Sex → Binary Encoding
Male=1, Female=0. Simple binary for biological sex-linked drug metabolism differences.
⚖️ Class Imbalance Handling
The dataset has significant class imbalance — Tamoxifen (226) vs Bleomycin (1). Addressed with SMOTE + class_weight balancing.
SMOTE: Synthetic minority oversampling
class_weight = "balanced" in sklearn
Result: F1-macro improved by ~12%
🤖 Model Selection & Performance
Selected: Random Forest Classifier — Best balance of accuracy, interpretability, and SHAP compatibility. Frequency-based lookup used as inference engine for speed; RF provides the SHAP feature importance weights used in XAI panel.
